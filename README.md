# EduTrack demo

This static demo uses eight fictional learners from `mockData.js`. It does not include the original student CSV.

## Run locally

Open `index.html` in a browser. Chart.js loads from a CDN, so charts need an internet connection.

Student edits and attendance registers are stored only in the current browser's local storage. They are not synced between visitors or devices.

## Publish with GitHub Pages

Upload the contents of this folder to the root of the repository's `main` branch. In the repository settings, enable GitHub Pages and choose `Deploy from a branch`, branch `main`, folder `/(root)`.
